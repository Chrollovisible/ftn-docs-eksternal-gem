# Aturan Main Token

Setiap token punya aturan main: **berapa jumlah totalnya**, **dibagikan ke siapa saja**, dan **untuk apa dipakai**. Kumpulan aturan ini sering disebut **tokenomics**.

Mudahnya, bayangkan sebuah voucher yang jumlahnya sudah ditentukan sejak awal. Aturan yang jelas membuat semua orang tahu bagaimana voucher itu beredar.

Anda tidak perlu memahami halaman ini untuk mengecek keaslian produk atau menerima hadiah.

:::note[Dalam penyusunan]
Angka resmi tokenomics (jumlah total token dan pembagiannya) akan dipublikasikan di halaman ini setelah versi resminya dikonfirmasi tim.
:::
