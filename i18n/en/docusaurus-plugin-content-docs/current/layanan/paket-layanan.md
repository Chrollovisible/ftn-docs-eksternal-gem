# Service Plans

Flagshiiip offers two plans for brands.

## Starter

For brands that want to start protecting their products from counterfeiting.

- **Price**: Rp500 per sticker
- **Minimum order**: 10,000 stickers

Features:

- Unique QR code on every sticker
- Blockchain-based authenticity verification
- Scanning through the app (Android and iOS)
- Monitoring dashboard (scans, locations, activity)
- Certificate showing the product as authentic or verified
- Anti-duplication (each QR code can only be claimed once)

## Custom

For brands that need a more flexible and advanced system. Pricing is arranged through consultation.

Includes all Starter features, plus:

- Custom QR and sticker design
- Branding integration (logo and verification landing page)
- Token or loyalty system
- Custom smart contract

## Quick comparison

| Feature | Starter | Custom |
|---|---|---|
| Unique QR per sticker | Yes | Yes |
| Blockchain-based verification | Yes | Yes |
| Monitoring dashboard | Yes | Yes |
| Anti-duplication | Yes | Yes |
| Custom QR and sticker design | No | Yes |
| Branding integration | No | Yes |
| Token or loyalty system | No | Yes |
| Custom smart contract | No | Yes |
