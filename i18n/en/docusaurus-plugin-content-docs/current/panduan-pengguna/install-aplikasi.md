# Install the App

The Flagshiiip app is available for Android and iOS. On Google Play, the app is named **FTN Apps**.

## Installation steps

1. Open Google Play (Android) or the App Store (iOS).
2. Search for **FTN Apps** or **Flagshiiip**.
3. Tap **Install** and wait until it finishes.
4. Open the app.

## Creating an account

1. On the start screen, choose **Sign Up Now**.
2. Enter your email, password, and password confirmation.
3. Tick the agreement to the policy shown, then choose **Sign Up**.
4. If you already have an account, choose **Log In**.

After logging in, continue to [Scan the QR](./scan-qr.md).

:::caution[Needs team verification]
The app name in the App Store, the official download link, and the start screen layout need to be checked against the latest version of the app.
:::
