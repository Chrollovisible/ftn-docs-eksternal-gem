# Claim Tokens

After a product is verified and a wallet is connected, users can receive authentication from the blockchain and claim tokens as a loyalty program reward.

## Overview of the steps

1. Scan the product's QR code and make sure the result is verified.
2. Connect your wallet in the app.
3. Follow the instructions in the app to claim tokens.

Each QR code can only be claimed once.
